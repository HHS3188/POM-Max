# Performance Optimization MAX 使用说明

适用环境：**A Dance of Fire and Ice 3.2.0**、UnityModManager

## 安装

1. 退出游戏
2. 下载 GitHub Release 中的 `POM-Max-2.1.5.zip`，使用 UnityModManager 安装
3. 也可以运行同一 Release 中的中文一键安装 CMD
4. 启动游戏，在 UMM 中启用 **Performance Optimization MAX**

安装器会自动寻找 Steam 游戏目录，仅替换 `Mods\POMMax` 的核心文件，保留 `Settings.xml`，并在替换前创建备份

## 档位

### Off

关闭本模组的性能修改，用于兼容性排查

### MAX

适合日常游玩重特效谱面

- 目标帧率 240
- 关闭 VSync 与抗锯齿
- 阻止谱面的 `SetFrameRate` 强制帧率事件
- 跳过加载前的阻塞式清理
- 优化高开销谱面事件并禁用背景视频
- 装饰数据上限 20000
- 对大型自定义纹理进行 2 倍降采样
- 加载完成后显示本次优化结果

### EXTREME

只追求极限性能的档位

- 目标帧率 10000
- 启用 MAX 的全部基础优化
- 降低同一用户会话中其他普通进程的优先级
- 提高游戏进程优先级并请求 Windows 高性能电源计划
- 降低阴影、实时反射、软粒子、LOD 等画质开销
- 对大型自定义纹理进行最高 8 倍降采样

为避免黑色装饰、动画抖动和特效链中断，`2.1.5` 不再运行时停用装饰物，不删除 `MoveDecorations` 事件，也不进行位置或 Shader 跳帧

## 优化结果

每次加载自定义 `.adofai` 谱面后，模组会显示一次小型汇总，内容包括：

- 事件和装饰处理数量
- 纹理内存节省
- 加载耗时
- 综合负载优化比

窗口会避开编辑器左上角控件，并按当前分辨率限制大小

## 兼容性

- 不修改游戏 DLL、资源文件或谱面原文件
- 编辑器中的谱面数据不会被保存成优化后的版本
- 纹理处理保留透明通道、过滤模式、循环模式和各向异性设置
- 结果界面、判定图像、文字、UI、碰撞体、星球跟随和贴地装饰会受到保护
- 检测到旧 `optimiz` 同时启用时会记录冲突提示，建议只保留一个优化模组

## 出现显示异常时

1. 先从 `EXTREME` 切换到 `MAX`
2. 重新加载谱面
3. 若仍异常，切换到 `Off` 确认是否由本模组引起
4. 提交 UMM 日志、谱面名称、游戏版本、模组版本和所选档位

禁用或卸载模组后，运行时画质、进程优先级、电源计划和计时器请求会尝试恢复

# Quick Guide

- `Off`: disables POM-Max changes
- `MAX`: stable strong optimization with 2x large custom-texture downsampling
- `EXTREME`: maximum performance with process and quality tuning plus alpha-safe 8x downsampling
- Version `2.1.5` does not use destructive runtime decoration caps, decoration deactivation, `MoveDecorations` removal, or position/Shader frame skipping
- The mod does not modify game files or save optimized chart data back to the editor

---

# 빠른 사용 안내

- `Off`: POM-Max 최적화를 끕니다
- `MAX`: 대형 커스텀 텍스처를 2배 축소하는 안정적인 강한 최적화입니다
- `EXTREME`: 프로세스 및 품질 조정과 알파 채널 보존 8배 텍스처 축소를 사용하는 최고 성능 모드입니다
- `2.1.5`는 런타임 장식 강제 비활성화, `MoveDecorations` 제거, 위치 및 Shader 프레임 건너뛰기를 사용하지 않습니다
- 게임 파일과 편집기의 원본 차트 데이터는 수정하지 않습니다

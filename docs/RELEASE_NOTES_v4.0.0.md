# Performance Optimization MAX 4.0.0

## 直接下载

- `POM-Max-4.0.0-OneClick-Installer.cmd`：直接下载并运行，不需要手动解压；使用 ASCII 文件名避免 GitHub 和旧版 Windows 丢失中文字符
- `POM-Max-4.0.0.zip`：供 UnityModManager 手动安装
- `SHA256SUMS-4.0.0.txt`：用于校验两个安装产物

一键安装 CMD 会自动查找 Steam 多库中的游戏目录，打印本版更新内容和每一步安装进度。如果该目录的游戏正在运行，脚本会强制结束对应进程，再执行备份、原子替换和安装后哈希校验。`Settings.xml` 不会被覆盖；写入失败时会自动回滚。

## V4 主要更新

- 新增低分配帧时间遥测，显示平均值、P95、P99、峰值、内存和渲染计数
- 新增自适应纹理上传调度，仅调整 POM-Max 管理的 Unity 异步上传预算
- 新增保守的静态装饰位置快速路径和着色器状态指纹缓存
- 将每帧全量装饰碰撞扫描替换为定期校验的有效碰撞列表
- 新增有界 PNG/JPEG 头信息缓存，避免重复读取未变更文件
- 每个快速路径都有独立的三次异常熔断，并提供 Harmony 补丁所有权和运行程序集身份诊断
- UMM 页面重做为概览、档位、高级和诊断四个分区，中文为默认语言
- 自动迁移旧版高风险设置，保留游戏原生清理、视频、装饰、输入和判定逻辑

## 实机验证

在 ADOFAI 3.3.1 / Unity 6000.3.10f1 上完成 UMM 加载、多页设置、外部谱面加载、真实装饰谱面 0-100% 游玩和结算验证。该次样本中：

- 谱面事件保留 83，装饰保留 7
- 纹理载入 5，处理 5，估算纹理字节从 42,071,128 降至 663,840
- 静态位置更新跳过 3,327 次，着色器状态跳过 1,533 次，避免无效碰撞检查 23,296 次
- 帧时间平均/P95/P99/峰值为 1.47/1.88/2.78/5.49 ms
- 所有模块熔断器保持关闭，UMM 无 POM-Max 异常

这些数据是单次实机样本，不代表所有谱面与硬件的固定提升比例。

## 安全边界

V4 不删除谱面事件或装饰，不修改游戏文件、Together 文件、输入、判定、音频时钟或谱面时钟，不强制 GC，不调整 Windows 电源计划，不节流其他进程。
